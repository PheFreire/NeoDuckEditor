**h31**

Conhecido como o hash "vezes 31", é o mesmo algoritmo usado internamente pelo `hashCode()` de `String` em Java. Multiplica o hash acumulado por 31 a cada caractere (`h = 31 * h + c`)

- Velocidade: rápido, pois a maioria dos compiladores otimiza a multiplicação por 31 para `(h << 5) - h`, evitando uma multiplicação real
- Qualidade: distribuição boa e validada em produção por décadas através do Java, sendo confiável para strings comuns
- Quando usar: ótima escolha padrão para tabelas hash de uso geral, principalmente quando se quer um comportamento já amplamente testado
- Observação: como os demais hashes dessa lista, não é seguro contra colisões propositais, e por usar um primo pequeno (31), tende a gerar mais colisões que primos maiores em conjuntos de dados muito grandes

```c
uint32_t h31_hash(const char* s, size_t len) {
    uint32_t h = 0;
    while (len) {
        h = 31 * h + *s++;
        --len;
    }
    return h;
}
```
